# Nilan HMI Card

A Lovelace card that replicates the **Nilan CTS602 HMI** front screen, driven by your Genvex Connect entities.

- Photo-accurate background with live HA overlays
- Visual editor with one-click device auto-fill
- Tap-to-more-info, alarm popup, settings popup
- All assets bundled inside the JS file

See the [README](https://github.com/msvinth/ha-nilan-card) for full documentation.
